## Gaps / notes (v8)

- **dips**: Replaced with distinct Ketut Subiyanto pair — arms-locked top (`4803885`) vs elbows ~90° bottom (`4803876`). Bench/ledge variation (not parallel bars).
- **sit-ups**: Replaced with matching outdoor series — lying-flat start (`8038626`) vs curled-up exec (`8038632`).
- **skull-crushers**: Still low-res Commons two-panel crops (~320×384). No clear free lying skull-crusher start/exec pair on Pexels/Unsplash in this pass (overhead/seated tricep extensions are a different movement).
- **jogging**: Unchanged (optional). Start remains track crouch rather than standing ready; no quick standing-ready CDN hit this pass.
- **lunges / squats / burpees start**: Share the same Andrea Musto standing-ready studio shot.
- **planks / push-ups start**: Share the same high-plank whole-body photo; planks exec is forearm plank.
